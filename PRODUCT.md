# Learning Studio

## Platform

Windows-first Electron desktop application with React/TypeScript interfaces.

## Product purpose

A general-purpose learning workspace combining persistent subjects and chats, structured learning memory, optional curricula and checks, scientific figures, reference material, notes and a connected knowledge graph.

## Confirmed constraints

Upgrade the existing application. Preserve SQLite records, evidence, themes, settings, exports and authentication. The reading experience is primary. Figures stay inline; no compulsory side laboratory. Selection feedback belongs near its source. Assessment is optional. Model output and scientific approximations must be labeled honestly. Never invent learner biography, quota, atomic coordinates or numerical results.

ChatGPT remains the default provider. Other/local providers are optional configurations, never silently selected or billed. No local model is installed by this upgrade.

## Acceptance

Clear, readable lessons and meaningful controls; no user-facing reply stopwatch. Search and graph browsing should remain useful with many records. Verify the actual Windows application and portable exports.
