# Learning Studio active learning interface

Mode: Operate shell, Read teaching content. The user explicitly rejects the whole incumbent design and has already delegated design decisions instead of an interview. Preserve existing data, features, themes and scientific state. The old folio is an anti-reference; its permanent prompt dock and transcript hierarchy are rejected.

## Direction contract

THESIS: Learning Studio is a place to work through a subject. My learning leads to a subject pathway and a focused sequence of real lesson sections. Questions support the lesson rather than defining the entire product.

OWN-WORLD: A contemporary campus learning itinerary supplies deep teal identity, warm neutral ground, clear sans-serif hierarchy, compact native controls and generous teaching space. Theme tokens remain authoritative. The signature is a connected, selectable course/section trail based on actual saved content, with coverage separate from demonstrated evidence.

STORY: Resume actual work or choose a subject. See the goal and pathway, study one meaningful section, manipulate its figures, optionally check understanding, then continue. Ask opens on demand; full conversation history and all advanced tools remain findable.

FIRST VIEWPORT: The built desktop surface uses a single-row 64px course-app header above a 276px-default resizable subject path and a focused learning workspace. A section navigator names the current content; its reading/experiment area dominates. Back/Next and Ask about this page form a learning action row. No permanent chat composer, repeated role labels or compulsory visualization panel. Home instead leads with actual resume work, subject pathways and real resources. Below 1050px Contents becomes a deliberate overlay; the native 864px capture verifies Reading open below the global navigation.
